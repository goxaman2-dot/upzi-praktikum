# Поиск в 4 канала: подключение

Все четыре канала работают через OpenRouter, поэтому нужен один ключ. Yandex Cloud для этого сайта не нужен.

| Канал | Модель OpenRouter | Что делает |
|---|---|---|
| Perplexity | `perplexity/sonar-pro` | быстрый поиск, источник к каждому утверждению |
| Perplexity Reasoning | `perplexity/sonar-reasoning-pro` | поиск с рассуждением, ход мысли показан отдельно |
| Gemini + веб | `google/gemini-3.8-flash` с веб-поиском | другой поисковый движок, источники из аннотаций |
| DeepSeek Think | `deepseek/deepseek-v4.1-flash`, режим рассуждения | сверяет найденное тремя каналами |

## Установка воркера (около 5 минут)

1. Cloudflare → Workers & Pages → Create → Worker. Назовите его, например, `upzi-search` и нажмите Deploy.
2. Edit code: замените всё содержимое файлом `search-worker/worker.js` и снова нажмите Deploy.
3. Settings → Variables and Secrets:
   - `OPENROUTER_API_KEY` (тип Secret): ключ OpenRouter, можно тот же, что в прокси синтетического чата;
   - `ACCESS_CODE`: тот же код доступа, что в синтетическом чате.
4. Откройте в браузере `https://upzi-search.<имя>.workers.dev/status`. Должен появиться JSON, где у четырёх каналов стоит `"configured": true`.
5. На сайте вставьте этот адрес (без `/status`) в поле «Прокси поиска», введите код и нажмите «Проверить связь».

Поле «Прокси чата» заполнять не обязательно. Это запасной путь: если прокси поиска недоступен, DeepSeek и Gemini пойдут через прокси синтетического чата.

Модели можно заменить переменными `PERPLEXITY_MODEL`, `PERPLEXITY_R_MODEL`, `GEMINI_MODEL`, `DEEPSEEK_MODEL`, указав имена из каталога openrouter.ai/models.

## Расходы

Каналы платные, деньги списываются с баланса OpenRouter:
- запрос Perplexity обходится примерно в 1–3 цента, Reasoning немного дешевле;
- веб-поиск Gemini около 1,4 цента за запрос;
- DeepSeek стоит доли цента.

Бесплатные модели OpenRouter (с пометкой `:free`) поиска не дают.

Чтобы сэкономить, выключите лишний канал щелчком по его плашке: выбор запоминается.

## Как работает сайт

- Три поисковых канала работают одновременно и независимо друг от друга.
- Их источники попадают в сводный список. Повторы убраны, у каждой записи указано, какой канал её нашёл. Если источник нашли два канала или больше, слева у строки стоит зелёная черта.
- DeepSeek Think получает ответы каналов и сводный список. Он отмечает расхождения, оценивает надёжность источников и ссылается только на номера из списка.
- «Где искать»:
  - «Научные публикации» включает академический режим Perplexity и подсказывает каналам ориентироваться на КиберЛенинку, eLibrary и dissercat;
  - «Нормативные акты РФ» ограничивает Perplexity сайтами consultant.ru, garant.ru, pravo.gov.ru, fstec.ru и digital.gov.ru.
- Кнопки «Подбор литературы» и «Проверка ссылок» вставляют готовые шаблоны запросов.
